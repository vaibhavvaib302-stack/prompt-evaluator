
# PromptLab – Interactive Prompt Evaluator & Benchmarking Tool

PromptLab is a web-based prototype designed to demonstrate and compare three popular prompt engineering techniques: Zero-Shot Prompting, Few-Shot Prompting, and Chain-of-Thought Prompting.

The application provides a unified interface to configure prompts, execute simulated benchmark tests, and compare evaluation metrics.

## Features

- **Multiple Model Configurations:** Select from GPT-4o, GPT-4o Mini, Gemini 2.5 Flash, and Claude 3.5 Sonnet.
- **Prompt Configuration:** Customize system prompts, user tasks, and expected outputs.
- **Prompt Engineering Techniques:**
  - Zero-Shot Prompting
  - Few-Shot Prompting
  - Chain-of-Thought Prompting
- **Benchmark Execution:** Run all three techniques and view simulated responses.
- **Performance Metrics:** View estimated latency, token counts, and approximate quality scores.
- **Sample Test Cases:** Sentiment Analysis, Python Code Debugging, and Math Word Problems.
- **Report Export:** Download benchmark results in JSON format.
- **Responsive Dashboard:** Dark-themed interface built with React and Tailwind CSS.

## Installation and Setup

### Prerequisites

- Node.js
- npm

### Steps

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project:

   ```bash
   cd prompt-evaluator
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   `http://localhost:5173/`

## How It Works

1. Select a model configuration.
2. Adjust Temperature and Top-P parameters.
3. Enter a system prompt, user task, and expected output.
4. Choose a sample test case or enter a custom task.
5. Run the benchmark.
6. Compare the generated responses and estimated metrics.
7. Export the results as a JSON report.

## Evaluation Metrics

- **Latency:** Simulated execution time for each technique.
- **Input Tokens:** Approximate token count calculated from prompt length.
- **Output Tokens:** Approximate token count calculated from response length.
- **Quality Score:** Word-overlap similarity between the generated response and target output.

## Important Limitations

This is a Phase 1 prototype.

- Responses are locally simulated and are not generated by actual language models.
- Model selection is a configuration option and does not make external API calls.
- Temperature and Top-P are displayed as configurable parameters but do not affect the simulated responses.
- Token counts are approximate estimates.
- Quality scores use basic word-overlap comparison, not semantic evaluation.
- Cost calculation and real-time API benchmarking are not implemented.
